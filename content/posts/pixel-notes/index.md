像素字体最容易被误用的一点，是把它放在长文正文里。12px 的汉字像素字体，在 12px 里当然完整，但完整不等于适合长时间阅读。

所以正文默认交给系统无衬线字体：18px / 1.9，栏宽 36em。像素字体退到标题、导航、日期和图注；需要时用 `Aa` 把正文切回像素。

```text
reading mode: 18px system sans / 1.9
pixel mode:   12px design × 2 = 24px / 40px
pixel measure: 32em 约 32 个汉字 / 行
```

像素模式下行高 40px、栏宽 32em，段落之间留 24px。像素字体的字面本来就密，只有把周围的空间放开，字与字之间才会重新有呼吸。

> 可读性不是字体单独决定的。字号、行高、栏宽、对比度、留白，缺一不可。

这也是为什么站里有一个 `Aa` 按钮。默认是系统无衬线字体，适合读长文；想看像素字时切回去。两者都保留，不互相取代。

黑色背景也不是纯黑。页面是 `#080808`，文字是 `#f0f0f0`。对比度足够高，但不会让白色在黑色上发光。照片保留彩色，界面保持单色。低分辨率的字和高分辨率的照片放在一起，才有意思。
